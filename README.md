# 🎓 Student Management System

A simple student management system built with **Python** and **MySQL**. Perform basic operations like adding, updating, deleting, and viewing student records via the command-line interface.

## 🛠️ Tech Stack

- Python  
- MySQL  
- MySQL Connector (Python library)

## 📌 Features

- Add new student records  
- Update existing student details  
- Delete student entries  
- View all stored student data
